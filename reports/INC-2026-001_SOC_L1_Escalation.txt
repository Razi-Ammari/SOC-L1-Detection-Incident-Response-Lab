Summary:
During the investigation, multiple failed authentication attempts were detected against the user testuser on WIN10-ENDPOINT. The source IP address was identified as 192.168.100.30, corresponding to the Kali Linux attacker machine in the lab environment.

In addition to the authentication failures, suspicious PowerShell activity was detected through Sysmon logs. The investigation showed execution of Document_Update.exe and powershell.exe with suspicious command-line indicators such as -EncodedCommand, -ExecutionPolicy Bypass, and DownloadString.

Evidence Collected:
1. Splunk failed logon detection using Windows Security Event ID 4625.
2. Source IP investigation showing 192.168.100.30 as the origin of failed attempts.
3. Sysmon Event ID 1 showing suspicious process creation.
4. Process tree correlation showing cmd.exe and Document_Update.exe launching powershell.exe.
5. Final L1 investigation summary showing multiple suspicious alert categories.
